## What is pseudo file?
- A pseudo file is a virtual file that does not physically exist on disk.
  It is generated by the kernel when you read it.

## /proc/loadavg
- It has 5 fields.
- The first 3 numbers are the load averages over the last 1, 5 and 15 minutes:
  the average number of tasks running or waiting for the CPU. It's a queue
  length, not a CPU percentage.
- On my machine (12 threads), a load of 12 means the CPU is fully busy;
  above 12 means tasks are waiting in line.
- The 4th field (`1/238`) is running/total: 1 task running right now,
  238 tasks in total.
- The 5th field (`6718`) is the PID of the most recently created process.

## /proc/meminfo
- Shows memory stats in kB. `free -m` reads this same file and shows it in MB.
- `MemTotal`: all the RAM this system can use. WSL gets half of my 32 GB
  by default, so it's ~15.5 GB.
- `MemFree`: RAM that nothing is using at all (~12.2 GB).
- `Cached`: RAM Linux uses to cache files so reads are faster (~2.5 GB).
  It's given back immediately when a program needs memory.
- `MemAvailable`: RAM programs can actually use = free + reclaimable cache
  (~14.8 GB). That's why it's bigger than `MemFree`.
- Proof: `15140340 kB / 1024 = 14785 MB`, exactly the "available" column
  in `free -m`.

## /proc/net/dev
- One line per network interface. The first 2 lines are headers.
- Columns are split into two groups: `Receive` (left) and `Transmit` (right).
- The 1st column of each group is bytes. On my machine `eth0` had received
  ~290 MB and sent ~7 MB.
- `lo` is the loopback interface: the machine talking to itself.
- Yesterday my WSL IP was on `eth1`, today the traffic is on `eth0`.
  Interface names can change, so never hardcode them. Read all interfaces
  and let the user choose.

## Counters and rates
- Most numbers in `/proc` are counters: they only go up since boot.
- One reading alone can't tell "how fast". You need two readings:
  `rate = (value2 - value1) / seconds between them`.
- Example from `/proc/uptime`: the 1st field (seconds since boot) went up
  by 5 in 5 seconds. The 2nd field (total idle time of all CPUs) went up
  by 60. `60 / 5 = 12`, so all 12 CPU threads were idle the whole time.
- Same idea for network: bytes per second = difference in bytes / seconds.
- Prometheus does this with the `rate()` function.

## /proc vs df
- Disk usage isn't in `/proc`. `df` gets it from the `statfs` system call.
- My WSL disk is a virtual disk that can grow up to 1 TB, 6.9 GB used.
